# Entrance Choreography

The interface should enter progressively instead of appearing all at once.

## Recommended Order

1. Background
2. Layout shell
3. Main cards
4. Secondary cards
5. Buttons
6. Indicators
7. Ambient effects

## Timing

- Stagger: 40ms–120ms
- Main surface duration: 240ms–320ms
- Secondary details: 160ms–240ms

## Avoid

- Simultaneous reveal
- Dramatic scaling
- Large bounce
- Excessive page-load animation
